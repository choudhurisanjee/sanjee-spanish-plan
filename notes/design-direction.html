The study ledger

The triathlon plan is built out of soft colored chips and emoji — the visual grammar of a dashboard. This is the opposite bet: a ruled log book. Type does the work, color says almost nothing, and every number lines up in a column. Simpler to look at and simpler to build.

Type

SF Mono for all structure, labels and figures — it ships on your phone, so there's no webfont to load and nothing to fall back from. SF Pro for the two places actual prose appears.

Color

Paper, ink, and one blue-violet used only for the goal and milestones. Today is marked by inverting the row to solid ink, not by a hue — so nothing incomplete ever reads as an alarm.

Structure

No cards, no shadows, no rounded corners. Hairline rules, a strict left edge, right-aligned tabular figures. Activity types are two-letter codes instead of emoji.

Type coding

What this changes

  • Emoji become two-letter codes. GR / AN / LI / SP / MO. They align in a column, which emoji never do, and they stop the app from looking like every other tracker.
  • Color stops carrying meaning. Done is a filled bracket and a strikethrough. Today is an inverted bar. Nothing needs a legend.
  • Anki gets a seven-box strip instead of five identical items cluttering the tray — it's a daily habit, so it should look like one.
  • The build gets smaller. No per-type palette, no webfont, no card shadows. Roughly forty lines of CSS carry the whole look.
